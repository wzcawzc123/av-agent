# av-agent 通用化架构补全计划（已完成 P0 + P1）

## 目标
通用售前方案 Agent：导入产品库+常规模板 → 说需求 → 输出专业方案（多系统、品牌可指定/组合、库可无限增大）。

## 核心架构思想
- **模板管结构**（系统+角色+数量）
- **产品库管货源**（品牌×型号×价格，角色标签检索）
- **引擎做确定性计算**（席位/功率/通道/屏体）
- **LLM 只做翻译与补全**（不自由选型）
