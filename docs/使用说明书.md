# AV Agent 使用说明书

> 适用版本：1.0.0　|　场景：电脑运行服务 + 手机浏览器控制（支持 exe 免装分发）

## 1. 运行环境要求

| 项 | 要求 |
|---|---|
| 电脑系统 | Windows / macOS / Linux（建议 64 位） |
| Python | ≥ 3.12（仅源码运行时需要；用 exe 分发则无需安装） |
| 网络 | 电脑需能访问模型 API（DeepSeek、OpenAI 等） |
| 局域网 | 电脑与手机处于同一局域网（或手机可访问电脑 IP） |
| 可选 | LibreOffice（生成 PDF 时需要） |

## 2. 两种运行方式

### 方式 A：Windows exe（推荐给最终用户，免装环境）

在 Windows 电脑上双击 `build_exe.bat`，脚本自动完成依赖安装与打包，产出 `dist\AVAgent.exe`（单文件）。把该 exe 发给用户即可：

1. 双击 `AVAgent.exe` 启动，终端窗口显示访问地址与口令，浏览器自动打开界面；
2. 首次运行在 exe 同级目录生成 `data\` 目录（数据库、密钥、访问口令；**口令重启不变**）；
3. 手机关闭终端窗口即停止服务（也可按 Ctrl+C）。

> 打包必须在 Windows 电脑上执行；exe 内已包含 Python 运行时与全部依赖，用户电脑无需安装任何环境。

### 方式 B：源码运行（开发 / 自部署）

```bash
git clone https://github.com/wzcawzc123/av-agent.git
cd av-agent
pip install -r requirements.txt
```

设置访问口令并启动（口令用于保护所有接口，请自行设置强口令）：

```bash
# Windows (PowerShell)
$env:AV_ACCESS_TOKEN="你的口令"
uvicorn app.main:app --host 0.0.0.0 --port 8000

# macOS / Linux
AV_ACCESS_TOKEN=你的口令 uvicorn app.main:app --host 0.0.0.0 --port 8000
```

- `--host 0.0.0.0` 让手机可通过局域网访问（只在本机用可改 `127.0.0.1`）。
- `--port 8000` 可换成任意空闲端口。
- **口令必须显式设置**：不设置时系统会生成随机口令且不显示，你将无法登录。

启动成功的标志：

```
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000
```

首次启动会自动创建 `data/`、`output/`、`uploads/` 目录和 SQLite 数据库。

### 2.1 手机访问

1. 电脑上查局域网 IP（Windows：`ipconfig`；macOS/Linux：`ip addr` 或 `ifconfig`）。
2. 手机浏览器打开 `http://<电脑IP>:8000`。
3. 首次使用按提示输入访问口令（会保存在手机浏览器本地）。

## 3. 快速上手（三步生成方案）

1. **配置模型**：点右上角 ⚙️ 打开「模型提供商」，选择提供商（内置 13 家，如 `deepseek`、`MiMo`）并填 API Key 保存；内置不够用时点「➕ 新增自定义提供商」，填名称 + Base URL + API Key + 模型列表即可。
2. **导入产品库**（可选但推荐）：点右上角 📦，上传公司产品 Excel（表头：`产品名称|型号|参数|底价|市场价|分类`），页面会显示导入结果与产品列表，让生成结果自动带底价/市场价。
3. **发需求**：输入如「100平会议室音响方案」，按对话引导补齐信息，确认后自动生成并下载。

## 4. 详细操作

### 4.1 配置模型（⚙️）

1. 打开页面后点击右上角 ⚙️ 按钮，进入「模型提供商」列表。
2. 选择要使用的提供商，点「编辑」填写 API Key（内置提供商已带 Base URL 和模型列表，只需填 Key）；点「设为当前」切换默认提供商。
3. 内置 13 家：OpenAI、Anthropic、阿里百炼、DeepSeek、Kimi、MiMo（小米）、MiniMax、阶跃星辰、硅基流动、OpenRouter、智谱 GLM、百度文心、Google Gemini。

**新增自定义提供商**（对接任意 OpenAI 兼容 / Anthropic / Gemini 服务）：

1. 提供商列表点「➕ 新增自定义提供商」；
2. 填名称（如“公司中转”）、Base URL（如 `https://gw.example.com/v1`）、API Key、模型列表（逗号分隔，如 `gpt-4o,gpt-4o-mini`）；
3. 协议类型选「OpenAI 兼容 / Anthropic / Gemini」；
4. 保存后点「设为当前」即可使用。

**进阶操作**：

- **远程拉取模型**：编辑提供商时点「远程拉取模型」，自动请求该服务 `GET /models` 接口，把可用模型填入列表（需先保存 API Key）；
- **复制**：内置或自定义都可复制为新的自定义提供商，便于改 Base URL 试中转；
- **重置**：内置提供商可一键恢复出厂定义（保留已填 API Key）；
- **删除**：自定义提供商可删除，内置不可删。

> 未配置模型时发送消息，Agent 会提示「尚未配置模型。请点击右上角 ⚙️ 选择提供商并填写 API Key 后重试」，不会报错。

### 4.2 导入产品库（📦）

1. 点击头部 📦 按钮打开产品库面板。
2. 选择公司产品 Excel 文件（首行为表头）：

```
产品名称 | 型号 | 参数 | 底价 | 市场价 | 分类
双8寸会议音箱 | AV-208 | 8寸×2,120W | 1800 | 3200 | 音箱
```

3. 点「上传导入」，页面显示「导入完成：新增 n，更新 m」并刷新产品列表。

- 列顺序不限，多余列忽略；`型号` 为唯一键，重复导入 = 更新，新型号 = 新增。
- 兼容旧表头「低价」（映射到底价字段）。

### 4.3 管理模板库（🗂️）

点击头部 🗂️ 按钮打开模板库面板，可注册两类模板：

**常规配置模板**（生成时按面积自动匹配，无精确面积时取最接近的）：
- 名称 + 类型选「常规配置模板」+ 适用面积（㎡，如 100）+ 场景（可选）→ 注册。

**文档模板**（Word/PPT/偏离表文件）：
- 名称 + 类型选对应项 + 文件路径（如 `D:/tpl/方案模板.docx`）→ 注册。

Word 模板占位符约定：正文段落中 `{{项目名称}}`、`{{方案正文}}` 会被自动替换；没有模板时自动生成默认版式。PPT 套用母版后逐页填入大纲标题与要点；偏离表模板从现有表继续追加「需求/状态/说明」行。列表中的模板可一键删除。

### 4.4 对话式收集需求

输入需求后 Agent 会依次澄清缺失信息，按 面积 → 场景 → 预算 → 品牌 → 交付物 顺序追问。示例：

```
你：100平会议室音响方案
Agent：项目面积大概多少平方米？
你：100
Agent：主要用途/场景是什么（会议室、展厅、报告厅…）？
你：多功能会议室，兼顾日常会议和简单报告
Agent：客户预算大概多少？
你：10万左右
Agent：有没有品牌偏好？
你：没有
Agent：需要哪些交付物？文字方案 / 偏离表 / PPT 都可以选。
你：文字方案、偏离表、PPT
```

信息齐全后 Agent 汇总需求：

```
已确认以下需求，请确认后开始生成：
- 面积：100
- 场景：多功能会议室…
- 预算：10万左右
- 品牌：未提供
- 交付物：文字方案(Word), 偏离表(Excel), PPT
```

### 4.5 生成与下载

1. 确认无误点「确认，开始生成」；要改点「修改需求」继续对话。
2. 生成期间显示进度条（SSE 实时推送：匹配模板 → 适配设备清单 → 逐个生成文件）。
3. 完成后出现下载链接，点击即可保存到手机：
   - `doc` → 方案.docx
   - `deviation` → 偏离表.xlsx
   - `ppt` → 方案.pptx
   - `pdf` → 方案.pdf（需 LibreOffice）

生成文件同时保存在电脑端 `output/proj_{项目id}/` 目录（exe 模式下位于 exe 同级目录的 `output\` 下）。

## 5. 常用接口速查

```bash
TOKEN=你的口令
BASE=http://<电脑IP>:8000

# 健康检查
curl $BASE/api/health

# 对话
curl -X POST $BASE/api/chat -H "Content-Type: application/json" -H "X-Access-Token: $TOKEN" \
  -d '{"text":"100平会议室音响方案"}'

# 查询任务
curl $BASE/api/tasks/<task_id> -H "X-Access-Token: $TOKEN"

# 上传产品 Excel
curl -X POST $BASE/api/products -H "X-Access-Token: $TOKEN" -F "file=@products.xlsx"

# 保存模型配置
curl -X PUT $BASE/api/settings/model -H "Content-Type: application/json" -H "X-Access-Token: $TOKEN" \
  -d '{"provider":"deepseek","api_key":"sk-xxxx"}'

# 注册常规配置模板（按面积）
curl -X POST $BASE/api/templates -H "Content-Type: application/json" -H "X-Access-Token: $TOKEN" \
  -d '{"name":"100平会议室","type":"config","area":100,"scene":"会议室"}'

# 删除模板
curl -X DELETE "$BASE/api/templates/1?type=config" -H "X-Access-Token: $TOKEN"
```

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 打开页面提示「访问口令无效」 | 口令输错或换过 `AV_ACCESS_TOKEN`/删除了 `data\access_token.txt`；用当前口令重新输入 |
| 发送消息提示「尚未配置模型」 | 还没配模型或配置未保存成功；点 ⚙️ 重新配置 |
| 生成任务失败、报 SSL/连接错误 | 电脑无法访问模型 API：检查网络、代理、API Key 是否正确、账户是否有额度；自定义提供商可先用「连接测试」验证 |
| PDF 转换失败提示需 LibreOffice | 电脑安装 LibreOffice 后重启服务；PDF 依赖 Word 先生成成功 |
| 手机打不开页面 | 确认同一局域网、防火墙放行 8000 端口、启动用 `0.0.0.0` |
| 重启服务后对话上下文丢失 | 会话槽位在内存中；重新发起对话即可（历史项目仍在数据库） |
| 产品价格没出现在方案里 | 设备价格回填依赖产品库导入成功；确认 Excel 表头含「底价」「市场价」且型号不为空 |
| exe 双击后没反应 | 检查是否被杀毒软件拦截；exe 需与 `data/` 有写权限的目录（放桌面/非系统目录） |
| 想固定 exe 的访问口令 | 设置环境变量 `AV_ACCESS_TOKEN` 后再启动 exe（环境变量优先于自动生成） |

## 9. 软件更新

客户端内置「设置 → 软件更新」：

1. 打开设置抽屉，滚动到「🔄 软件更新」；
2. 点「检查更新」：客户端会请求 GitHub Releases 最新版信息（默认
   `https://api.github.com/repos/wzcawzc123/av-agent/releases/latest`），
   与本地版本比较；
3. 有新版本时显示版本号、更新说明与下载链接；点击链接下载新版 exe，
   关闭旧程序后用新版替换即可（数据保存在 exe 同目录 `data/`，更新不影响）。

**私有仓库**：仓库为私有时，需先在「更新配置」中填入 GitHub Token
（只读 Release 权限即可），保存后再点检查更新。

**发布者流程**：改 `app/version.py` 的 `VERSION` → 提交推送 →
Windows 上跑 `build_exe.bat` → `gh release create v1.0.1 dist\AVAgent.exe --title "v1.0.1" --notes "更新说明"`。
