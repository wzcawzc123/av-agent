# AV Agent 使用说明书

> 适用版本：0.1.0　|　场景：电脑运行服务 + 手机浏览器控制

## 1. 运行环境要求

| 项 | 要求 |
|---|---|
| 电脑系统 | Windows / macOS / Linux（建议 64 位） |
| Python | ≥ 3.12 |
| 网络 | 电脑需能访问模型 API（DeepSeek、OpenAI 等） |
| 局域网 | 电脑与手机处于同一局域网（或手机可访问电脑 IP） |
| 可选 | LibreOffice（生成 PDF 时需要） |

## 2. 部署与启动

### 2.1 获取代码并安装依赖

```bash
git clone https://github.com/wzcawzc123/av-agent.git
cd av-agent
pip install -r requirements.txt
```

### 2.2 设置访问口令并启动

访问口令用于保护所有接口，请自行设置一个强口令：

```bash
# Windows (PowerShell)
$env:AV_ACCESS_TOKEN="你的口令"
uvicorn app.main:app --host 0.0.0.0 --port 8000

# macOS / Linux
AV_ACCESS_TOKEN=你的口令 uvicorn app.main:app --host 0.0.0.0 --port 8000
```

- `--host 0.0.0.0` 让手机可通过局域网访问（只在本机用可改 `127.0.0.1`）。
- `--port 8000` 可换成任意空闲端口。
- **口令必须显式设置**：不设置时系统会生成随机口令且不显示，你将无法登录。

启动成功的标志：

```
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000
```

首次启动会自动创建 `data/`、`output/`、`uploads/` 目录和 SQLite 数据库。

### 2.3 手机访问

1. 电脑上查局域网 IP（Windows：`ipconfig`；macOS/Linux：`ip addr` 或 `ifconfig`）。
2. 手机浏览器打开 `http://<电脑IP>:8000`。
3. 首次使用按提示输入访问口令（会保存在手机浏览器本地）。

## 3. 快速上手（三步生成方案）

1. **配置模型**：点右上角 ⚙️，选择提供商（如 `deepseek`），粘贴 API Key，保存。
2. **导入产品库**（可选但推荐）：上传公司产品 Excel（表头：`产品名称|型号|参数|底价|市场价|分类`），让生成结果自动带底价/市场价。
3. **发需求**：输入如「100平会议室音响方案」，按对话引导补齐信息，确认后自动生成并下载。

## 4. 详细操作

### 4.1 配置模型

1. 打开页面后点击右上角 ⚙️ 按钮。
2. 选择提供商、填写 API Key；模型名可留空（使用该提供商默认模型）；Base URL 一般留空。
3. 点「保存」，系统提示「模型配置已保存」。

已内置提供商：deepseek、openai、qwen、kimi、glm、wenxin、gemini。

> 未配置模型时发送消息，Agent 会提示「尚未配置模型。请点击右上角 ⚙️ 选择提供商并填写 API Key 后重试」，不会报错。

### 4.2 导入产品库

产品 Excel 首行为表头，至少包含「型号」列：

```
产品名称 | 型号 | 参数 | 底价 | 市场价 | 分类
双8寸会议音箱 | AV-208 | 8寸×2,120W | 1800 | 3200 | 音箱
```

- 列顺序不限，多余列忽略。
- 同型号重复导入 = 更新该产品；新型号 = 新增。
- 导入完成后可在 `GET /api/products` 核对（当前前端页面未提供产品列表入口，可用浏览器开发者工具或接口调用查看）。

> 说明：0.1.0 前端以对话生成为主，产品/模板管理入口为 API。可用任意 API 调试工具（如浏览器控制台 fetch）调用，请求头带 `X-Access-Token`。

### 4.3 对话式收集需求

输入需求后 Agent 会依次澄清缺失信息，按 面积 → 场景 → 预算 → 品牌 → 交付物 顺序追问。示例：

```
你：100平会议室音响方案
Agent：项目面积大概多少平方米？
你：100
Agent：主要用途/场景是什么（会议室、展厅、报告厅…）？
你：多功能会议室，兼顾日常会议和简单报告
Agent：客户预算大概多少？
你：10万左右
Agent：有没有品牌偏好？
你：没有
Agent：需要哪些交付物？文字方案 / 偏离表 / PPT 都可以选。
你：文字方案、偏离表、PPT
```

信息齐全后 Agent 汇总需求：

```
已确认以下需求，请确认后开始生成：
- 面积：100
- 场景：多功能会议室…
- 预算：10万左右
- 品牌：未提供
- 交付物：文字方案(Word), 偏离表(Excel), PPT
```

### 4.4 生成与下载

1. 确认无误点「确认，开始生成」；要改点「修改需求」继续对话。
2. 生成期间显示进度条（SSE 实时推送：匹配模板 → 适配设备清单 → 逐个生成文件）。
3. 完成后出现下载链接，点击即可保存到手机：
   - `doc` → 方案.docx
   - `deviation` → 偏离表.xlsx
   - `ppt` → 方案.pptx
   - `pdf` → 方案.pdf（需 LibreOffice）

生成文件同时保存在电脑端 `output/proj_{项目id}/` 目录。

## 5. 配置模板库（进阶）

生成时按面积自动匹配「常规配置模板」，匹配不到精确面积时取最接近的。模板数据通过 API 写入 SQLite：

| 接口 | 用途 |
|---|---|
| `POST /api/templates` | 注册 Word/PPT/偏离表模板文件路径：`{name, type, file_path, description}`，type 取 `doc`/`ppt`/`deviation` |
| `GET /api/templates` | 查看已注册模板 |
| `DELETE /api/templates/{id}` | 删除模板 |

Word 模板占位符约定：正文段落中 `{{项目名称}}`、`{{方案正文}}` 会被自动替换；没有模板时自动生成默认版式。PPT 套用母版后逐页填入大纲标题与要点；偏离表模板从现有表继续追加「需求/状态/说明」行。

示例（注册一份 Word 方案模板）：

```bash
curl -X POST http://<电脑IP>:8000/api/templates \
  -H "Content-Type: application/json" \
  -H "X-Access-Token: 你的口令" \
  -d '{"name":"标准方案模板","type":"doc","file_path":"D:/tpl/方案模板.docx","description":"公司标准版式"}'
```

## 6. 常用接口速查

```bash
TOKEN=你的口令
BASE=http://<电脑IP>:8000

# 健康检查
curl $BASE/api/health

# 对话
curl -X POST $BASE/api/chat -H "Content-Type: application/json" -H "X-Access-Token: $TOKEN" \
  -d '{"text":"100平会议室音响方案"}'

# 查询任务
curl $BASE/api/tasks/<task_id> -H "X-Access-Token: $TOKEN"

# 上传产品 Excel
curl -X POST $BASE/api/products -H "X-Access-Token: $TOKEN" -F "file=@products.xlsx"

# 保存模型配置
curl -X PUT $BASE/api/settings/model -H "Content-Type: application/json" -H "X-Access-Token: $TOKEN" \
  -d '{"provider":"deepseek","api_key":"sk-xxxx"}'
```

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 打开页面提示「访问口令无效」 | 口令输错或电脑端已重启且换过 `AV_ACCESS_TOKEN`；用正确口令重新输入 |
| 发送消息提示「尚未配置模型」 | 还没配模型或配置未保存成功；点 ⚙️ 重新配置 |
| 生成任务失败、报 SSL/连接错误 | 电脑无法访问模型 API：检查网络、代理、API Key 是否正确、账户是否有额度 |
| PDF 转换失败提示需 LibreOffice | 电脑安装 LibreOffice 后重启服务；PDF 依赖 Word 先生成成功 |
| 手机打不开页面 | 确认同一局域网、防火墙放行 8000 端口、启动用 `0.0.0.0` |
| 重启服务后对话上下文丢失 | 会话槽位在内存中；重新发起对话即可（历史项目仍在数据库） |
| 产品价格没出现在方案里 | 设备价格回填依赖产品库导入成功；确认 Excel 表头含「底价」「市场价」且型号不为空 |
