# AV Agent 宣讲案书

> 宣讲对象：公司管理层 / 销售团队 / 客户　|　版本：v1.2.0　|　时长建议：10–15 分钟（含演示）

## 一、开场：一个真实的痛

> 各位，我们团队做售前的同事每天在干什么？

- 深夜赶方案：一个 100 平的会议室，从需求到 Word + 偏离表 + PPT，**少则半天，多则一两天**；
- 产品知识都装在几个人脑子里：哪个型号配哪个场景、底价市场价多少、怎么填偏离表——**人走了知识就没了**；
- 客户一句话改需求：面积 200 变 300、品牌换掉，全套文档从头再来。

**结果：售前工程师 70% 的时间在做"复制粘贴"，而不是做"方案"。**

今天介绍的 AV Agent，就是把这件事**变成一句话的事**。

## 二、产品是什么

**AV Agent：音视频售前工作流 Agent。**

工程师用自然语言说出需求，它自动完成"澄清 → 确认 → 生成"全流程，产出专业交付文件：

```text
"100平会议室音响方案，预算10万，品牌JBL"

        ↓ 对话式澄清（面积/场景/预算/品牌/交付物逐项补齐）

        ↓ 产品库 + 模板库 + 大模型语义适配

  ┌────────────┬────────────┬────────────┐
  │ Word 方案  │ Excel 偏离表│  PPT 演示  │   ← 三件套一键生成
  └────────────┴────────────┴────────────┘
```

**核心能力一览：**

| 能力 | 一句话说明 |
|---|---|
| 对话式需求采集 | 缺什么问什么，不问废话 |
| 产品库/模板库 | 公司资产沉淀，导入 Excel 即用 |
| 大模型语义适配 | 13 家主流模型 + 自定义，换模型不换代码 |
| 招标改单 | 招标 Excel/Word/PDF 上传 → 自动解析匹配 → 人工确认 → 转 BOM |
| BOM 清单编辑器 | 增删改行、实时小计、一键重出报价，单价为 0 自动标"待询价" |
| 工程工具箱 | 会议/广播/LED/偏离表四个引擎，**不配模型也能用** |
| 知识库 | 公司规范自动注入，答案贴合内部资料 |
| 手机端 | 手机浏览器即用，无需安装 App；可在机场/客户现场改方案 |

## 三、核心优势（为什么是我们）

### 1. 为售前场景而生，不是通用聊天机器人
- 通用 AI 只会"生成一段文字"；AV Agent 会**按业务规则算功率、配型号、填偏离表**，输出的是**可交付的文件**，不是参考意见。

### 2. 公司资产沉淀，人走知识不走
- 产品底价、市场价、模板、历史项目记忆全部入库；
- 方案生成**自动回填最新价格**，不会用过期报价。

### 3. 零门槛部署，三种形态
- **源码运行**（开发/测试）→ **Windows exe 双击即用**（客户端分发）→ **docker-compose 企业部署**（PostgreSQL + Redis，多组织）；
- 手机浏览器控制电脑，**局域网联动**，不用装 App。

### 4. 架构面向未来，扩展成本极低
- 引擎注册表：新增"视频会议"等引擎 = **一行注册 + 业务函数**；
- Agent 化工作流：Planner 拆解 → 6 Agent 可插拔 → 运行全落库可审计；
- 297 条自动化测试护航，18 项真机实测验证。

### 5. 安全可靠
- 访问口令鉴权（防伪造绕过）、密钥磁盘加密存储；
- 私有部署，数据不出内网。

## 四、演示脚本（5 分钟）

| 步骤 | 操作 | 重点讲解 |
|---|---|---|
| 1 | 手机打开系统首页，展示界面结构 | 一个页面搞定聊天/产品/模板/设置 |
| 2 | 输入："帮我做100平会议室音响方案" | 演示 Agent 缺省追问（预算？品牌？） |
| 3 | 补充信息后确认 | 需求汇总确认，防返工 |
| 4 | 输入"广播系统 1F大厅 24只T-601 12只T-105" | 演示广播引擎：分区解析 → 功率计算 → 功放推荐，**无需模型配置** |
| 5 | 生成 Word/偏离表/PPT，展示进度条与下载 | 三件套一键生成、SSE 实时进度 |
| 6 | 打开 BOM 编辑器改数量、重出 Excel | 清单实时小计、"待询价"标注 |
| 7 | 上传一份招标清单 | 自动解析匹配产品库，生成偏离表 |
| 8 | 打开设置页展示模型提供商列表 | 13 家内置 + 自定义 + 测试连接 |

## 七、FAQ 速答

- **需要什么电脑配置？** 普通办公 PC 即可；Windows exe 免装 Python。
- **模型必须自己买 Key 吗？** 对，自带 13 家主流厂商，挑一家填 Key 即可；工程工具箱（会议/广播/LED/偏离表）不依赖模型也能跑。
- **数据安全？** 全私有部署，数据不离开内网；密钥加密存储、访问口令保护。
- **不会用怎么办？** 手机端"使用说明书"内建文档，另附发布更新操作手册。
- **能接我们自己的产品吗？** 能，产品库 Excel 一键导入，模板库支持 docx/pptx 直接上传注册。
