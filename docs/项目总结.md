## 一、项目是什么

**AV Agent** 是为音视频行业售前技术工程师打造的对话式工作流 Agent：工程师用自然语言描述项目需求（"100 平会议室音响方案"），系统自动澄清缺失信息、确认需求，依托**公司产品库**与**模板库**，由大模型语义适配，自动生成整套交付文件（Word 方案 / Excel 偏离表 / PPT），并通过手机浏览器 + 电脑端/Windows exe 双形态交付。

一句话定位：**把售前从"人手一份方案"变成"对话即方案"**。

## 三、v1.2.0 做了什么

### 1. 前后端接口全面审计
- 前端 33 个 API 调用逐一核对，**100% 有后端实现**，无悬空/拼写错误端点；
- 后端预留接口（workflow 运行历史、组织、用户、知识库、项目详情扩展）评估完成，属面向未来扩展，无需处理。

### 2. 引擎注册表化（架构收敛）
- 会议 / 广播 / LED / 偏离表四个引擎此前识别关键词、执行、摘要分散三处维护，新增引擎易出现"能识别但执行不到"的洞；
- 统一为 `register_engine()` 注册表：意图识别、执行分发、摘要展示全部从注册表读取，**新增引擎 = 一行注册 + 业务函数**。

### 3. 知识库接入意图解析（RAG-lite）
- 知识库从"只有 CRUD"升级为参与生成：用户输入 → 关键词检索（纯 Python，无向量库依赖）→ top3 文档片段注入意图解析提示词；
- 检索失败静默降级，不影响主流程。

### 4. Bug 修复
- **广播分区解析**：`1F大厅 24只T-601` 中楼层前缀 `1F` 被误解析为型号 F（数量 1），导致分区功率 0.0W；修正后楼层前缀正确归入分区名。

### 5. 安全加固
- API Key 等敏感配置**磁盘加密存储**（Fernet，`enc:` 前缀）；密钥缺失自动生成；
- 访问口令中间件**防 XFF 头伪造绕过**（直接校验对端地址）；
- 设置页 API Key 掩码显示（`sk-s***ced`）。

### 6. 质量验证
- 测试：**297 条全部通过**（新增引擎触发端到端、安全加固、知识库注入、广播解析等 5 条）；
- 真机实测：**18 项全部通过**（鉴权四场景、四引擎触发与 xlsx 下载、供应商/产品库/模板列表、密钥掩码与加密落盘、招标上传、知识库读写删）；
- Windows exe 打包脚本复核无误。

### 7. 发布
- 推送 `origin/main`，打 tag `v1.2.0`，发布 GitHub Release；

## 五、未来方向（建议）

1. **知识库升级**：关键词检索 → 向量检索 + 混合排序，支持文档切片与多格式（PDF/Word）自动入库；
2. **多租户落地**：组织/用户模型已就绪，补齐登录、权限粒度与审计报表；
3. **引擎扩展**：视频会议、舞台灯光、楼宇智能等新引擎按注册表一行接入；
4. **移动端 App**：当前为手机浏览器 PWA 形态，可封装原生壳提升体验；
5. **模板市场**：方案模板/产品库按行业共享，支持团队协作沉淀。
